rython API Reference

Canvas

240 columns (x) × 136 rows (y), origin (0,0) = top-left.

Pixel Drawing

screen.cls()
screen.pix(x, y, color)
screen.line(x1, y1, x2, y2, color)
screen.rect(x, y, w, h, color, fill)
screen.circ(x, y, radius, color, fill)
screen.text(str, x, y, size, color)

Backward-Compatible

screen.set(x, y, ch, fg, bg)
screen.print(text, x, y, fg, bg)
screen.clear()
screen.scroll(n)
screen.refresh()

Colors

C64 palette names: black white red green blue cyan purple yellow orange brown lightred darkgray gray lightgreen lightblue lightgray

Or full RGB: "#ff8800", (255, 136, 0)

Input

key = screen.read_key()
screen.mouse_x, screen.mouse_y
screen.is_mouse_down()

Quick Example

import time, math
for t in range(60):
    screen.cls()
    for x in range(240):
        y = int(68 + math.sin(x * 0.05 + t * 0.1) * 30)
        screen.line(x, y, x, y + 2, "#53d769")
    screen.text(f"frame {t}", 4, 4, 1, "white")
    screen.refresh()
    time.sleep(0.03)
